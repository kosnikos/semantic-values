How to read the columns:

- **Macro-F1 EN / EL proxy**: a value counts as predicted when its merged stance is endorse, reject or contested; *mention* does not count (Touché labels say a value is behind the argument, not that it is merely named). *+mention* is the same with mention counted. Labels with no gold support in the set are left out of the average (declared), and appear in the per-value table marked `no gold`. `n` is the number of items (owner: articles) behind each score; a run that is not done or does not cover every document is shown as `partial n/N`, is not scored and is not ranked.
- **Gap EN-EL**: English macro-F1 on the parallel items minus Greek-proxy macro-F1, signed; both sides are the same items.
- **Stance agreement**: agreeing / co-present (value present for both the run and the owner), then the rate. *Contested* counts as a disagreement unless the owner's stance is contested. **Missed**: owner-present, not predicted. **Spurious**: predicted, owner said not present. **Unjudged**: predicted, no owner label yet (the blind pass fills these). Counts, not only rates: the owner set is small.
- **Cost / 1,000 articles**: owner-set run cost / owner articles x 1,000. It is the cost of *paragraph-unit* tagging of *news articles*, not of arguments.
- **Latency**: (finished - started) / segments for synchronous runs; message-batch runs show `batch`. A resumed run includes the time it sat stopped.
- The lexicon baseline emits only *mention* (spec 5.3), so its strict macro-F1 is always 0: the **+mention** column is its meaningful figure.
- —: the configuration has no run on that input.

## Decision rule

From the tagging-method spec, section 5.6. Touché23 macro-F1 (English and Greek proxy, averaged) ranks the configurations; the owner set is a gate: a configuration whose stance agreement on the owner set is clearly worse than the best is dropped; among the rest, prefer the cheapest within 0.02 macro-F1 of the best. Twenty articles cannot rank eight configurations on stance alone.

Builder's choices where the spec is open: "clearly worse" means more than 0.10 below the best agreement rate; a configuration with no owner run is not gated; the lexicon baseline is a comparison and is never recommended; a configuration missing the Greek-proxy run is ranked on English alone.

## Caveats

- Touché23 items are short arguments, not news, so absolute scores flatter every model. Use them to rank configurations, not as accuracy on newspapers.
- The Greek text is a machine-translated proxy of the English items, not Greek newspaper prose; the gap measures sensitivity to the language of the same items.
- The owner set is small (about 20 articles): read the counts, not the percentages, and do not expect it to separate close configurations.
- Touché23 labels presence only; stance is measured on the owner set alone.
- Cost and latency are for paragraph-unit tagging of news articles, taken from the owner-set run.
